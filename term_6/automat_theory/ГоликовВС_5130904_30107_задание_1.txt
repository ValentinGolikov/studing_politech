Формулировка задания:
Проверить эквивалентность двух заданных конечных автоматов с 4-5 состояниями.

Придумайте (можно графически) эти два автомата.
Выходной алфавит рекомендуется двоичный.
Оне будет таковым, если вы испльзуете автоматы-распознаватели.

Не забудьте указать интерпретацию полученного решения:
эквивалентны автоматы или нет.

-------------------------------------------------------------------------

Создадим два конечных автомата: Автомат А и Б

Автомат А: "Сумматор по модулю 2 с накоплением"
Вычисляет сумму всех входящих битов по модулю два и выдает ее на выход

Состояния:
    a0 сумма четная (0), предыдущий выход 0
    a1 сумма нечетная (1), предыдущий выход 1
    a2 сумма четная (0), предыдущий выход 1
    a3 сумма нечетная (1), предыдущий выход 0

    | тек.сост  | сумм  | пред.выход | вход | нов.сумма | след. | выход |
    |    a0     |   0   |      0     |  0   |     0     |   a0  |   0   |
    |    a0     |   0   |      0     |  1   |     1     |   a1  |   1   |
    |    a1     |   1   |      1     |  0   |     1     |   a3  |   1   |
    |    a1     |   1   |      1     |  1   |     0     |   a2  |   0   |
    |    a2     |   0   |      1     |  0   |     0     |   a0  |   0   |
    |    a2     |   0   |      1     |  1   |     1     |   a1  |   1   |
    |    a3     |   1   |      0     |  0   |     1     |   a3  |   1   |
    |    a3     |   1   |      0     |  1   |     0     |   a2  |   0   |

    Начальное состояние а0

Автомат Б: "Детектор последовательности 01 с выходом"
Этот автомат выдает 1 каждый раз, когда во входном потоке встречается комбинация "01" (сразу после 0 идет 1).
В остальных случаях выдает 0.

Состояния:
    b0 начальное
    b1 последний вход был 0
    b2 последний вход был 1
    b3 обнаружение 01 (спец.состояние)
    b4 направляющее состояние (воспомогательное)

    | тек.сост  | вход  | след. | выход |
    |    b0     |   0   |   b1  |   0   |
    |    b0     |   1   |   b2  |   0   |
    |    b1     |   0   |   b1  |   0   |
    |    b1     |   1   |   b3  |   1   |   <- обнаружение "01"
    |    b2     |   0   |   b1  |   0   |
    |    b2     |   1   |   b2  |   0   |
    |    b3     |   0   |   b1  |   0   |
    |    b3     |   1   |   b4  |   0   |
    |    b4     |   0   |   b1  |   0   |
    |    b4     |   1   |   b2  |   0   |


Проверка эквивалентности
Слово: 0101

Автомат A:

    a₀: вх0 → вых0 → a₀ (сумма 0)

    a₀: вх1 → вых1 → a₁ (сумма 1)

    a₁: вх0 → вых1 → a₃ (сумма 1)

    a₃: вх1 → вых0 → a₂ (сумма 0)
    Выход A: 0110

Автомат b:

    b₀: вх0 → вых0 → b₁

    b₁: вх1 → вых1 → b₃ (нашли "01")

    b₃: вх0 → вых0 → b₁

    b₁: вх1 → вых1 → b₃
    Выход B: 0101

Различие: A выдает 0110, B выдает 0101 — уже на 2-м символе расхождение.

Вывод: Автоматы А и Б не эквивалентны
